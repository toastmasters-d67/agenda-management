# 海報模板 — 設計師交付說明

本資料夾的 `*_skeleton_v1.pptx` 是**token 骨架檔**：位置與樣式都只是示意，
請直接在上面套品牌視覺，**唯一要求是保留 token 與照片框名稱**。

| 骨架檔 | 頁數 | 用途 |
|---|---|---|
| `pre_event_skeleton_v1.pptx` | 1 | 活動預告海報 |
| `recap_skeleton_v1.pptx` | 7（封面 + 角色頁 ×5 + 封底） | 例會回顧 |

尺寸為 **1080 × 1350 px**（4:5）。每頁的**備忘稿（檢視 → 備忘稿）**寫了該頁規則。

---

## 五條規則（只有這五條）

1. **保留所有 `{{TOKEN}}` 文字**，不要改寫、不要翻譯、不要自行新增 token。
2. **一個 token 要在同一個文字框、同一段落、同一格式裡**——不要在 token 中間換字級／顏色／粗體，
   否則 PowerPoint 會把它拆成多段，程式替換會失敗。
   （想改樣式沒問題：整個文字框、整段一起改。）
3. **照片框請保留 shape 名稱**（`PHOTO_HOST`、`PHOTO_GROUP`、`PHOTO_ROLE_1~4`）。
   位置、大小、外框樣式都可自由調整；用「常用 → 選取 → 選取窗格」可查看／修改名稱。
4. **灰色斜體提示字可以刪除**（那是給你看的說明，不是內容）。
5. **回顧檔的頁序固定**為「封面 → 角色頁 ×5 → 封底」，請勿調換或插入新頁
   （程式會依實際角色數填頁，並刪掉沒用到的角色頁；5 頁角色頁 × 每頁 4 位 = 最多 20 位）。

## Token 一覽

### 預告海報
| Token | 內容 | 誰決定 |
|---|---|---|
| `{{HEADLINE}}` | 海報主標語 | **AI 生成**（請給最大視覺份量） |
| `{{THEME}}` | 主題中英，如「勇氣 Courage」 | 使用者輸入 |
| `{{QUESTION_ZH}}` / `{{QUESTION_EN}}` | 雙語問句（英文可能為空） | 使用者輸入 |
| `{{HOST_NAME}}` | 主持人姓名 | 使用者輸入 |
| `{{DATE}}` `{{TIME}}` `{{VENUE}}` `{{TRANSPORT}}` `{{FEE}}` | 活動資訊 | 使用者輸入 |
| `{{REGISTER_URL}}` | 報名連結 | 輸入／品牌固定值 |

### 回顧 · 封面
`{{HEADLINE}}`（AI 標語）、`{{MEETING_DATE}}`、`{{THEME}}`、`{{QUESTION_ZH}}`

### 回顧 · 角色亮點頁（每頁 4 位）
`{{GROUP_TITLE}}`（主持群／功能組／演講員／講評群）、
`{{ROLE_1_HEAD}}`～`{{ROLE_4_HEAD}}`（角色 · 姓名）、
`{{ROLE_1_BODY}}`～`{{ROLE_4_BODY}}`（AI 潤飾的亮點；沒用到會被清空）

### 回顧 · 封底
`{{NEXT_DATE}}` `{{NEXT_TIME}}` `{{NEXT_VENUE}}` `{{NEXT_TRANSPORT}}` `{{NEXT_FEE}}`
`{{REGISTER_URL}}`、`{{BRAND_SIGNATURE}}`（品牌定位句，逐字帶入）

## 完稿後請交付

| 項目 | 說明 |
|---|---|
| `.pptx` 檔 | 命名 `{用途}_{風格}_v1.pptx`，例如 `pre_event_navy_v1.pptx`、`recap_yellow_v1.pptx` |
| `preview.png` | 每套一張縮圖（回顧交封面那頁即可），供系統介面預覽 |
| 風格標籤 | 一兩個詞描述適合的主題語氣（如「沉靜／勇氣」「幽默／輕鬆」），供 AI 挑選模板 |
| 字體說明 | 用了哪些字體、是否可嵌入；若不可嵌入請改用通用中文字體（微軟正黑／PingFang／Noto Sans TC） |

> 想做多種風格供 AI 挑選，就用同一份骨架另存幾套（例如深藍沉靜、明亮活潑），token 不變即可。

---

## 重新產生骨架

```bash
python -m app.tools.make_token_skeleton
```

會覆寫本資料夾的 `*_skeleton_v1.pptx`（**不會**動到你完稿的檔案，只要檔名不同）。
